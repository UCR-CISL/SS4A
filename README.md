# ConnectedAirbag

Project website for the USDOT Safe Streets and Roads for All (SS4A) demonstration project
*Next-Generation AI-Driven Post-Crash Care Platform with Drones as First Responders (DFR)*,
led by the Collaborative Intelligence Systems Lab (CISL) at UC Riverside.

Served at https://cisl.ucr.edu/SS4A/ via GitHub Pages (branch `main`, root folder).

## Updating partner logos
1. Put the logo file in `assets/logos/` (SVG or a transparent PNG works best).
2. In `index.html`, find the partner in the `PARTNERS` list and add `logo: "<file name>"`.
Partners without a logo appear as a text tile with their name.
